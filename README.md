# DWIN STUDIO v4.0

Mobile-first AI workspace built with HTML5, CSS3, and Vanilla JavaScript.

## Features

* Glassmorphism + Cyberpunk UI
* Mobile-first responsive design
* PWA Support
* Secure API Vault
* Gemini API Integration
* Anthropic API Integration
* Azure OpenAI Integration
* GitHub PAT Storage
* Supabase Integration
* Vercel Deployment Support
* Railway Deployment Support
* Cloudflare API Support
* Offline Capability (Service Worker)
* Encrypted Local Storage
* Project Context Manager
* Dark Neon Theme

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/dwin-studio-v4.git

cd dwin-studio-v4
```

## Run

Open index.html in your browser

or

```bash
python -m http.server 8080
```

## Deploy

### Vercel

```bash
vercel
```

### Netlify

```bash
netlify deploy
```

### GitHub Pages

Push repository to GitHub and enable Pages.
